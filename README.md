# 🌲 Веб-симулятор викторины: Выжить в Тайге

Многопользовательский проект, представляющий собой интерактивный текстовый симулятор выживания в условиях дикой природы. Проект выполнен в рамках задания «Модульная разработка викторины».

Основной фокус разработки — строгое соблюдение принципов **Clean Architecture (3-Tier)**, изоляция слоев (данные, бизнес-логика, веб-интерфейс) и организация строгого контракта обмена данными.

---

## 🎮 Описание игрового процесса

* **Сеттинг:** Реалистичное выживание в глухой тайге.
* **Игровая механика:** Игрок сталкивается со сложными ситуациями (проверка знаний ОБЖ, ботаники, ориентирования). Каждый выбор напрямую влияет на показатели жизнеобеспечения.
* **Система параметров:** Менеджер очков динамически отслеживает три шкалы:
  * ❤️ **Здоровье** — общее физическое состояние.
  * 🔥 **Тепло** — уровень защиты от гипотермии.
  * 🍗 **Сытость** — показатель энергии и питания.
* **Условия финала:** Игра успешно завершается, если игрок ответил на все вопросы и дождался спасателей. Если хотя бы один показатель падает до `0` — наступает мгновенное поражение.

---

## 🛠 Технологический стек

* **Backend:** Python 3.14+, FastAPI (Асинхронный веб-сервер), Uvicorn.
* **Архитектура:** Чистая архитектура с использованием Modern Type Hints (`Generic`, `TypeAlias`, объединения типов `|`), `dataclasses` для строгих DTO контрактов.
* **Frontend:** Асинхронный JavaScript (Fetch API / AJAX), HTML5, CSS3 (Кастомный UI с эффектом Glassmorphism и индикаторами прогресса).
* **Тестирование и логирование:** Pytest (`pytest.ini`, `conftest.py`), стандартная библиотека `logging`.

## ⚙️ Архитектурные контракты и модульность
Проект спроектирован так, чтобы изменения в одном слое не ломали другие:

Слой данных (data) ничего не знает о веб-сервере или правилах начисления очков. Он лишь парсит JSON и возвращает иммутабельные dataclass-объекты.

Бизнес-логика (core) инкапсулирует в себе чистые математические правила выживания и правила переходов состояний викторины. Она полностью независима от HTTP-протокола.

Интерфейс (web) выступает исключительно в роли "переводчика" между действиями пользователя на фронтенде и методами quiz_engine.

## 🚀 Запуск и развертывание
1. Подготовка окружения
Убедитесь, что у вас установлен Python 3.14+. В терминале PyCharm выполните:

```Bash
# Активация виртуального окружения (для Windows)
.venv\Scripts\activate


# Установка зависимостей (если используется requirements.txt)
pip install fastapi uvicorn pytest
```

2. Запуск веб-сервера
Запустите файл main.py через PyCharm или через терминал:

```Bash
python main.py
```

После запуска откройте браузер по адресу: http://127.0.0.1:8000

## 🧪 Тестирование и логирование
Тесты: Для запуска набора тестов выполните команду:

```Bash
pytest
```

Конфигурация в pytest.ini автоматически подтянет фикстуры из conftest.py и протестирует граничные случаи (например, падение шкал ниже нуля или поведение движка при завершении вопросов).

Логи: Все ключевые события (старт сессии, выбор пользователя, критическое состояние параметров, завершение игры) логируются в папку logs/ и дублируются в консоль разработчика для удобной отладки точек интеграции.
